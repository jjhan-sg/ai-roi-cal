# AX Portfolio Manager & AI ROI Simulator - App 가이드

본 플랫폼은 **웹 브라우저 포털**뿐만 아니라 **설치형 독립 데스크톱/모바일 앱(App)** 형태로 실행할 수 있도록 완벽히 설계되어 있습니다.

---

## 1. 원클릭 독립 앱(App) 모드 실행 방법

### 방법 A. Windows 원클릭 실행 (추천)
- `app/start_app.bat` 파일을 더블 클릭합니다.
- Microsoft Edge 또는 Google Chrome의 **독립 실행 앱 창 (`--app` 모드)**으로 주소창 및 브라우저 툴바 없이 네이티브 데스크톱 앱처럼 즉시 실행됩니다.

### 방법 B. Python 스크립트 직접 실행
```bash
python app/start_app.py
```

---

## 2. PWA (Progressive Web App) 브라우저 기반 설치

Edge, Chrome, Safari 등 최신 브라우저에서 사이트 접속 후 상단의 **[📥 앱 설치]** 버튼 또는 브라우저 주소창 우측의 **'앱으로 설치'** 아이콘을 클릭하면:
- **Windows / macOS**: 바탕화면 및 시작 메뉴에 독립 실행형 애플리케이션으로 바로가기가 등록됩니다.
- **iOS / Android**: 모바일 브라우저의 '홈 화면에 추가'를 통해 네이티브 앱처럼 전체 화면으로 구동됩니다.
- **오프라인 캐싱 지원**: `sw.js` (Service Worker)와 `manifest.json`이 내장되어 네트워크가 불안정한 환경에서도 핵심 시뮬레이션 엔진이 로컬에서 정상 동작합니다.

---

## 3. 모바일 앱 뷰어 (Mobile Viewport Simulator)

- 웹 상단 우측의 **[📱 앱 모드 전환]** 버튼을 클릭하면 즉시 스마트폰/태블릿 해상도 규격으로 UI가 변환되며, 하단 모바일 내비게이션 바(홈, 카탈로그, 스튜디오, 포트폴리오, ROI, 성과)를 갖춘 모바일 전용 사용자 경험(UX)을 바로 체험할 수 있습니다.
